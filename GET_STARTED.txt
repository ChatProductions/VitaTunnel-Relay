VITATUNNEL v0.1

START HERE: README.md

This ZIP contains the real VitaSDK C source and an automated GitHub Actions
VPK build workflow, but no precompiled .vpk. The environment used to produce
this source did not have VitaSDK and could not download it.

Build in a GitHub repository: Actions -> Build VitaTunnel VPK -> Run workflow.
A separate workflow updates tunnel/manifest.txt when you create a game-*
GitHub release with exactly one .vpk attachment.

FIRST USE: Install VitaTunnel, open it, edit the generated config.ini once.
AFTERWARDS: Open VitaTunnel to transfer logs, download/install verified game
updates, and launch. Reopen after a test to upload logs. No background service.

DO NOT send GitHub tokens through ChatGPT. Public relay logs are PUBLIC.
