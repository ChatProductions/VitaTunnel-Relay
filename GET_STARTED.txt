1. GitHub Actions -> Build VitaTunnel VPK -> download VitaTunnel-v0.3.1-VPK.
2. Install VitaTunnel.vpk in VitaShell and open VitaTunnel.
3. On first run the included config.ini is copied to:
   ux0:data/vitatunnel/config.ini
   Untouched v0.1 placeholders are upgraded; modified configs stay unchanged.
4. The app waits for a real NFSMW AOT game release (tag game-*) in the relay.

without explicit opt-in; public GitHub logs are PUBLIC.
